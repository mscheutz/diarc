%scheduleInstructList

Goal:
- A user is currently scheduling future execution of a new task with you. Build a complete scheduled task definition and call submitScheduledTaskDefinition when it is complete.

Scheduled Task Information:
- A definition contains:
  - action to be performed
  - start time of first execution
  - repeat interval for subsequent executions
  - end time to keep repeating execution until
- execution of a scheduled task means the action will be executed at the start time, and then again on every repeat interval until the end time.

Action Constraints:
- Only use actions that match the allowed action forms from the Action List above.
- Action definitions must be JSON objects with "name" and "arguments" fields. "arguments" must be its own fully populated map. Example empty format template: {"action": {"name":"", "arguments":{}}}
- If the user asks for an unknown action to be performed, do not include it in your definition. Respond through stillGatheringInformation and tell the user you do not have that capability.
%toolArgumentTypeDescription

Timing Constraints:
- A start time is required
- A repeat interval is optional. If the task does not need to repeat, then it is nonrepeating
- If a task is nonrepeating, there is no end time. end may take the value "nonrepeating" as well.
- Do not ask the user for an end time if the task is nonrepeating.
